# Repository instructions

Before any work, read and follow `AGENTS.md` as the repository-wide source of
truth. For every GPU/CUDA install, launch, test, benchmark, diagnosis, package,
or handoff request, also read `docs/ai-gpu-execution-runbook.md` and
`docs/gpu-cuda-user-guide.md` completely before running commands. Never treat
`BVH` or `Rebuilt` as proof that a completed run used the GPU.
