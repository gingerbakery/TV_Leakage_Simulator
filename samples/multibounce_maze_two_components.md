# Multi-bounce maze STEP sample

`multibounce_maze_two_components.stp` contains exactly two named, coloured
solid components, in millimetres:

- `Maze_Tray_A`: floor, outer side/end walls, and the first baffle.
- `Maze_Cover_B`: roof and the second, opposing baffle.

Overall envelope: X 0–120, Y 0–60, Z 0–24 mm. The inlet is on the -X end
(Y 24–36, Z 8–16); the outlet is on the +X end (Y 6–18, Z 8–16). The
alternating baffles leave non-overlapping Y passages (42–57 and 3–18 mm), so
there is no straight line of sight through the maze. Light must find an
indirect path; the exact number of reflection events depends on its sampled
trajectory and optical properties, not on a fixed geometric count.

Suggested initial simulator setup (diagnostic, not a calibrated luminance
prediction):

1. Import the STEP and confirm two Components. Keep ROI off and both
   Components visible with TRACE ON.
2. Add a Datum Plane Emitter centred at (5, 30, 12) mm, facing +X, size
   8 × 8 mm. Use Lambertian, Forward and Total power = 1 lm. If the
   source is sparse at the first passage, try an Aim Target around
   (50, 49, 12) mm, then compare with Aim OFF.
3. Set both component surfaces to the same high-reflectance test material
   (for example Reflectance 0.85, Loss 0.15, Diffuse 1, Specular 0).
4. Add a Datum Plane Receiver centred at (123, 12, 12) mm, facing -X,
   size 12 × 10 mm, Acceptance Angle 90°. Ensure it covers the outlet.
5. Start with 100,000 rays to check the geometry, then increase to at least
   1,000,000 rays for a useful rare-path comparison. Use Max Reflections
   15 and Minimum Energy 1e-11. Keep the same Seed for case comparisons.

The Receiver and Emitter are virtual objects configured in the simulator;
they are intentionally not additional CAD components. A zero Receiver result
at low ray count does not by itself show the geometry is closed. Generated by
`generate_multibounce_maze.py` using CadQuery.

Local geometry check: the simulator's STEP importer read 2 named Components
and 112 display triangles; CadQuery read back 2 valid solids. A CPU diagnostic
with the settings above, Seed 42, angle-dependent reflectance OFF, and
100,000 rays produced 161 Receiver hits. All 161 stored Receiver paths had
at least 3 surface events (range 3–15). This demonstrates an indirect path
through the geometry, not a calibrated prediction or a guaranteed result for
different optical settings.
