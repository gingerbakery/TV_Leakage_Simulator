# TV 오른쪽 측면 하단 직선 이음매 샘플

사내 도면을 사용하지 않고 만든 축소 개발용 STEP입니다. 실제 제품의 치수나 광학 물성을 재현한 자료가 아닙니다.

- 전면은 +Z, 오른쪽 측면은 +X, 위쪽은 +Y입니다.
- 내부 크기는 120 × 80 × 16 mm, 외피 두께는 0.4 mm입니다.
- 오른쪽 데코와 샤시가 만나는 면 x=120.4 mm에서 y=8~28 mm의 20 mm 구간에만 직선 틈을 만들었습니다.
- 틈 폭은 깊이 방향 z=12~12+gap mm이며, 닫힘 / 0.1 / 0.3 / 0.5 mm 네 가지입니다. 각각의 실제 개구 면적은 0 / 2 / 6 / 10 mm²입니다.
- 화면, 데코, 샤시는 모두 불투명합니다. 틈 외에는 전체 밀폐 형상을 유지하며 ROI나 부품 제외를 사용하지 않습니다.
- 내부 104 × 64 mm 램버시안 면광원은 +Z를 향하고, 모든 모델에서 동일하게 총 1 lm입니다. 표면 반사율은 0.2인 임의의 무광 조건입니다.
- 모든 최종 프리셋은 CPU, 500,000 rays, 동일 seed 20260907, 최대 반사 깊이 4, 경로 저장 한도 5,000입니다.

## 시연

1. 원하는 gap 파일의 BITSAM을 불러옵니다.
2. 같은 이름의 STEP을 연결합니다.
3. 저장된 조건으로 Ray Tracing을 실행합니다.
4. Result의 3D 빛샘 보기로 들어간 뒤 오른쪽 측면으로 관측 방향을 바꿉니다. 확대하거나 조금 비스듬하게 회전해 틈의 폭과 빛을 확인합니다.

BITSAM에는 광원, 수광기, 물성, CPU 해석 조건을 미리 넣었습니다. 렌더링을 위한 별도 광학 조건 설정은 없습니다. 새로 연결한 CAD Case와 결과의 관계를 명확히 유지하기 위해 프리셋에 과거 결과를 포함하지 않았습니다. 폴더의 result.json은 재현 가능한 검증 기록입니다.

6면 수광기는 빛이 의도한 측면 틈으로만 빠져나갔는지 검증하는 가드입니다. 다른 방향 수광기에 도달했더라도 그 경로가 실제 +X 틈을 통과했는지 별도로 검사합니다. 빛의 위치는 수광기 표면 대신 실제 틈으로 역추적해 그려집니다.

## 재생성 및 검증

대용량 `*.result.json`은 Git에 포함하지 않습니다. STEP/BITSAM으로 앱에서 시연할 때는 필요하지 않습니다. 저장 결과 파일을 읽는 검증 스크립트를 실행하려면 저장소 의존성이 준비된 Python으로 아래 생성기를 먼저 실행합니다. 같은 이름의 합성 생성 자료를 갱신하므로 별도로 수정한 샘플은 먼저 다른 위치에 보관합니다.

```powershell
python scripts/generate_side_seam_samples.py
```

- scripts/generate_side_seam_samples.py: STEP와 CPU 요청·결과·교차 지점, validation.json 생성
- scripts/side_seam_project_helper.mjs: UI에서 읽을 수 있는 설정 전용 BITSAM 생성
- validation.json: 모든 저장 수광 경로의 의도한 측면 틈 교차 여부와 전체 수광 경로 저장 여부 확인

고정된 공통 표시 기준으로 비교하며 이 시제품의 화면 밝기를 nit로 해석하면 안 됩니다. 0.1 mm 틈은 좁은 통로 자체의 차폐 때문에 수광 표본과 광량이 적습니다. 유한한 표본 사이의 표현은 재구성이며 광량·국부 밝기·인지 한계의 실측 보정은 아직 하지 않았습니다.
