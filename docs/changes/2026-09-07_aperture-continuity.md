# 평면 틈 내부 연속광 재구성 — 2026-09-07

## 문제와 변경
기존의 개별 광점 halo와 연결 ribbon 중첩은 밝기 덩어리와 끊김을 만들었다. 확인된 평면 개구부 안에 에너지 밀도를 재구성하고 표면을 한 번씩 그리도록 교체했다.

- CAD mesh의 전체 외곽 평면과 일치하는 실제 삼각형으로 0.1 mm 셀의 차폐 여부를 판정한다. 셀 일부라도 금속과 겹치면 차폐로 취급한다. 샘플 이름이나 gap 치수를 하드코딩하지 않는다.
- 조사 영역 안에서 닫힌 경계를 갖고 실제 출구 표본이 들어 있는 개구부만 채택한다. 패치 가장자리로 열린 영역, 작은 해상도 미만의 틈, 지원하지 않는 변환과 부분 저장 결과는 점 표본으로 유지한다.
- 출구 ray 에너지를 같은 개구부 안의 이웃 셀에 1.8 mm 표준편차, 최대 4 mm 범위로 분배한다. 바깥 3–4 mm는 부드럽게 0으로 줄이며, 표본마다 분배 총량을 보존한다. 경계와 금속 장벽을 넘어 지름길로 연결하지 않는다.
- 9개 방향 구간을 유지하고 카메라 방향별 에너지를 합한 뒤 공통 표시 변환을 한 번 적용한다. 광선 수나 각 모델의 최댓값에 따른 자동 노출은 없다.
- 개구부별 수동 bilinear 보간으로 서로 다른 틈의 대각선 접점에서도 밀도가 섞이지 않게 했다. Nearest float texture를 사용해 float-linear 확장을 요구하지 않는다.
- 깊이 가림과 외관 색·마감·보조 조명 조절을 유지한다. 표시 생성은 결과 화면을 열 때만 수행하며 기존 Ray Tracing 연산 경로는 수정하지 않았다.
- 결과 화면을 나가면 모든 개구부 texture와 geometry/material을 해제한다.

## 실제 계산 검증
동일 CPU object-reference 방식으로 같은 seed와 광학 설정을 사용했다. 모든 receiver 도달 경로를 저장하도록 상한은 2,000으로 설정했다.

| 조건 | receiver hits | 출구 표본 incoming 에너지 합 (lm) | 재구성 표본 | 양의 밀도 영역 |
|---|---:|---:|---:|---:|
| 20,000 rays / 1 lm | 118 | 0.00254422204508635 | 118/118 | 20.25 mm² |
| 80,000 rays / 1 lm | 455 | 0.00265656871716317 | 455/455 | 20.25 mm² |
| 80,000 rays / 0.5 lm | 455 | 0.00132828435858158 | 455/455 | 20.25 mm² |

- 세 조건의 저장 출구 모두 알려진 합성 틈 내부에 있었다. 재구성 후 에너지 적분은 입력 합과 부동소수점 오차 범위에서 일치했다.
- 광원 출력을 절반으로 줄인 경우 모든 셀의 선형 밀도가 정확히 절반이다. 표시 압축 뒤 화면 pixel 값이 정확히 절반임을 뜻하지 않는다.
- 광선 수 20k→80k에서 총 출구 에너지 차이는 +4.42%, 공간 밀도 분포 L1 상대 차이는 26.94%였다. **국부 밝기는 아직 수렴했다고 판단하지 않는다.** 동일한 틈 모양과 광량 스케일을 유지하는 재구성과 표본 통계 수렴은 구분한다.
- 위 작은 샘플의 순수 재구성은 로컬 Node 검증에서 약 0.11–0.14초였다. 전체 해석이나 모든 CAD의 성능 보장은 아니다.
- 기존 gap_0p2 12개 표본에서는 804개 개구 셀 중 753개에만 유한 지지 범위가 닿았다. 근거 없는 꼬리 구간은 자동으로 채우지 않는다.

## 시연 및 회귀
- 실제 UI는 이전과 동일한 CPU 20,000-ray 조건으로 실행한 rt3-d4e183aee44a, 113 hits, 0.565%를 사용했다. 위 검증용 object-reference 결과 118 hits와 혼동하지 않는다.
- 새 3D 화면에서 평면 틈 범위 확인 상태, 정면 확대의 L자 연속광, 사선 회전 및 뒤쪽 기구 가림을 확인했다.
- 전체 기존 frontend 38개 파일 266개 테스트 통과, 추가 renderer 2개 테스트 통과. 최종 TypeScript, lint, production build 통과.
- 새 회귀 항목: 닫힌 면, 0.5 mm 틈, 인접 개구 분리, 셀보다 얇은 금속 장벽, 지원 범위/연산 상한, 광량 절반, ray 분할 불변성, 그리드 세분화, 경계 밖 무발광, 깊이 가림과 texture 해제.

## 한계와 다음 단계
- 평면 외곽 skin에 한정한다. 실제 임의 CAD의 곡면·단차·변환된 개구부 자동 추출은 미지원이며, 외곽 AABB 후보 출구를 일반 물리 개구부 검출 완료로 표현하지 않는다.
- 공간 bandwidth와 9개 방향 구간은 상대 표시용 근사다. 가림된 틈의 폭·두께에 의한 각도별 미세 배광, 시각적 번짐, nit·육안 검출 문턱은 미보정이다.
- 20k/80k 밝기 분포의 통계 차이가 남아 있어 일반 모델 완료 또는 빛샘 정확도 검증 완료를 선언하지 않는다.
- BITSAM의 저장 Result를 새 import Case에 재연결하는 별도 문제를 시연 준비에서 확인했다. 현재 유효한 실행 Case와 context가 다른 저장 결과는 3D 진입을 차단한다. 이번 작업에서는 이 검사를 우회하지 않고 앱에서 동일 조건을 다시 실행했다.
