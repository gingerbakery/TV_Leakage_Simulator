# 2026-09-10 — 저장 완료 확인창 정리

- 공통 AppDialog의 `p-4` 내용 여백과 `-mx-6/-mt-6` 제목 영역 여백이 달라 밝은 제목 영역이 창 밖으로 돌출되었다. 다른 편집창의 디자인은 변경하지 않고 저장 알림만 전용 확인창으로 분리했다.
- 폭 420px의 테마 일관된 단일 창, 제목 `저장 완료`, 파일명, 실제 저장 항목, `확인` 버튼으로 간소화했다. 긴 파일명은 줄바꿈하며 좁은 화면에서는 창 폭을 줄인다.
- `함께 저장된 항목`은 11px, 목록은 12px로 표시한다. 결과가 있을 때 `해석 설정 및 결과` 한 행으로 표시하며, 없으면 `해석 설정`만 표시한다.
- 브라우저 다운로드 위임은 `다운로드 시작`으로 구분하고, 기존 설정 전용 파일에는 CAD 별도 보관 안내를 유지한다. 저장 취소 시 완료창을 띄우지 않는다.
- 확인 버튼 기본 포커스, Enter/Escape 닫기, 닫은 뒤 이전 조작 위치로 포커스 복귀를 지원한다.
- 검증: 프론트엔드 275개 테스트(41개 파일), TypeScript 검사 및 production build 통과. 기존 Result Hook 의존성 lint 경고와 bundle/Canvas 테스트 경고는 유지된다.
- 실제 Edge headless 렌더링에서 라이트/다크 420px, 360px 화면에서 328px 창 폭, 긴 파일명 가로 넘침 없음 및 Enter/Escape 닫기를 확인했다. 검증 이미지/스크립트는 Git 제외 `outputs` 폴더에 보관한다.
- 저장 데이터 및 백엔드는 변경하지 않았다. 서버를 재시작하지 않고 frontend build만 갱신한다. 작업 저장 후 페이지 새로고침으로 적용한다.

## 후속 — 불러오기 완료창 통일

- 저장 전용 확인창을 `ProjectFileDialog`로 공통화하여 V2 및 정상 호환 V1 불러오기 완료에도 동일한 폭·배경·글씨 크기·확인 버튼을 적용했다.
- 제목 `불러오기 완료`, 파일명, `불러온 항목`, `CAD 모델 형상`, `해석 설정 및 결과`로 표시한다. 결과가 없는 경우에는 `해석 설정`만 표시한다.
- 정밀 형상 지연 준비 안내는 필요할 때만 짧게 유지한다. 비호환 CAD 경고, 이전 파일의 CPU 안전 복원 안내 및 명시적 GPU 선택 동작은 변경하지 않는다.
- 불러오기 버튼으로 포커스 복귀를 연결하고, 저장/불러오기 모두 Enter/Escape 동작을 유지했다.
- 검증: 프론트엔드 278개 테스트(41개 파일), TypeScript 및 production build 통과. Edge의 저장/불러오기 × 라이트/다크/좁은 화면 총 6개 조합에서 제목 영역 돌출·가로 넘침 없음과 Enter/Escape 닫기를 확인했다.
- 8788 서버에서 새 frontend bundle 응답을 확인했으며, 서버와 메모리 CAD 세션은 재시작하지 않았다.
