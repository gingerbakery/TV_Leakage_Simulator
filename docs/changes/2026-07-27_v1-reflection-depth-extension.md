# V1 최대 반사 횟수 확장

## 목적

- 반사율이 높은 소재와 갇힌 기구 구조에서 3회를 넘는 고차 반사 경로를 분석할 수 있도록 한다.
- 계산 시간을 통제하면서 결과 수렴 여부를 확인할 수 있는 V1 상한을 정의한다.

## 결정

- V1 최대 반사 허용 횟수를 `3`에서 `20`으로 확장한다.
- 기본값은 빠른 반복 계산을 위해 `1`로 유지한다.
- 권장값은 빠른 검사 `1`, 일반 설계 비교 `3`, 갇힌 고반사 구조 `10`, 수렴 확인 `20`이다.
- 프론트엔드와 백엔드 모두 `0~20` 범위를 적용해 API 직접 호출에서도 동일한 계약을 유지한다.

## 근거

- 현재 엔진은 반사된 광선을 여러 자식 ray로 분할하지 않고 하나의 표본 경로로 이어간다.
- 따라서 경로 수가 반사 횟수에 따라 기하급수적으로 증가하지 않으며, 계산량은 살아남은 ray의 실제 반사 횟수에 대체로 비례한다.
- 10회는 일반적인 갇힌 구조 분석에 사용하고, 20회는 10회 결과와 비교해 Receiver flux가 수렴하는지 확인하는 검증 설정으로 사용한다.
- 20회를 넘는 경로는 V2에서 적응형 종료와 Russian roulette 정책을 고도화한 뒤 재검토한다.

## UI

- `Max reflection depth`를 `Max reflections (0-20)`으로 변경한다.
- 입력창 아래에 1/3/10/20 사용 기준을 표시한다.

## 검증 계획

- 프론트엔드 설정값 `10` 허용과 `20` 초과값 clamp를 검증한다.
- 백엔드 설정값 `20` 허용과 `21` 거부를 검증한다.
- 10회 반사가 필요한 합성 광로에서 `max_depth=9`와 `10`의 Receiver 도달 차이 및 입사각 cosine을 포함한 예상 광량을 검증한다.

## 검증 결과

- 백엔드 다회 반사 회귀 테스트 7개가 통과했다.
- 프론트엔드 workspace store 테스트와 TypeScript typecheck가 통과했다.
- 반사율 `0.95`, ray `20,000`개의 합성 지그재그 광로에서 측정한 결과는 다음과 같다.

| 최대 반사 횟수 | 실행 시간 | Receiver hit | Receiver flux | 실제 최대 깊이 |
|---:|---:|---:|---:|---:|
| 1 | 0.4350초 | 0 | 0.000000000 lm | 1 |
| 3 | 0.8904초 | 0 | 0.000000000 lm | 3 |
| 10 | 2.5583초 | 20,000 | 0.423370949 lm | 10 |
| 20 | 2.5856초 | 20,000 | 0.423370949 lm | 10 |

- 이 광로에서는 10회 반사 후 Receiver에 도달하므로 상한을 20으로 설정해도 실제 계산은 10회에서 종료됐다.
- 실행 시간은 PC 상태와 CAD 복잡도에 따라 달라지며, 표의 값은 상한별 성능이 아니라 동일 조건에서의 상대 비교용이다.
