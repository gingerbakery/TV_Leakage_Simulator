# 좌표 입력 클릭 시 값 보존 및 커서 편집

- 날짜: 2026-09-08
- 상태: 구현, 회귀 테스트, 실제 Emitter 창 검증 완료
- 작업 폴더: `TV leakage simulator main`
- 기준 커밋: `d991858b0626c8bd2f2b713b14d385d82ffab5c1`
- 커밋/푸시: 수행하지 않음
- 사용자 자료: `좌표 입력 등.JPG`

## 원인

공통 `NumberInput`은 focus가 들어오면 값이 0인 경우 표시 문자열을 비우고, 0이 아니면 `input.select()`로 전체 문자열을 자동 선택했다. 따라서 좌표를 클릭한 뒤 숫자를 입력하면 기존 값 중간에 삽입되지 않고 전체 값이 바뀌었다. 첨부 이미지의 `-5.0` 전체 선택 상태와 일치한다.

## 변경된 입력 계약

| 동작 | 수정 후 |
| --- | --- |
| 클릭/Tab으로 입력창 진입 | 기존 숫자를 비우거나 프로그램에서 전체 선택하지 않음 |
| 마우스로 숫자 중간 클릭 | 브라우저의 기본 커서 위치 지정 동작을 유지 |
| 숫자 입력 | 현재 커서 위치에 삽입하거나 사용자가 선택한 부분만 교체 |
| 전체 교체 | 사용자가 Ctrl+A 또는 드래그로 명시적으로 선택한 후 입력 |
| 숫자를 전부 삭제 | 입력 중에는 공란 유지 |
| 공란 상태로 포커스 이동/Enter | 기존 정책대로 0으로 확정. 소수점 한 자리 표시 필드는 `0.0` |
| 음수, 소수, 방향키 증가/감소 | 기존 파싱 및 증감 규칙 유지 |

사용자 요청에 따라 이전의 'focus 시 0 자동 비우기' 정책을 '명시적으로 삭제한 경우에만 공란 유지'로 변경했다. Emitter 중심/회전뿐 아니라 동일한 공통 컴포넌트를 사용하는 Receiver, Transform, 기타 숫자 입력에도 적용된다. 읽기 전용 ROI 좌표의 복사용 전체 선택 동작은 변경하지 않았다.

소수점 표시 및 blur/Enter 시 반올림 규칙, 단위, 좌표 변환, 물성, 광학 계산, Apply/Save 흐름은 변경하지 않았다.
