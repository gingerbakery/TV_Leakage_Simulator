# Receiver Heatmap LightTools형 좌표축 디자인

## 기준

- LightTools Receiver 분석 화면처럼 Heatmap 데이터 영역과 좌표축을 분리한다.
- Heatmap 내부를 가로지르던 중앙 십자선, `(0,0)` 배지, `±X/±Y` 배지를 제거한다.
- X축은 플롯 하단, Y축은 플롯 우측에 배치한다.

## 변경

- Receiver 폭과 높이에 따라 실제 물리 종횡비를 유지하는 기존 동작은 보존했다.
- X/Y 범위에 맞춰 `1, 2, 2.5, 5 × 10^n` 간격의 읽기 쉬운 눈금을 자동 생성한다.
- 양 끝 경계, 0 좌표, 중간 주요 좌표를 mm 단위 숫자로 표시한다.
- X축 제목은 `X (mm)`, Y축 제목은 `Y (mm)`로 표시한다.
- Y축은 Receiver 로컬 `+Y`가 플롯 위쪽에 오도록 유지한다.
- Heatmap 색상표를 청색→청록→녹색→황색→주황→적색의 과학 시각화 팔레트로 변경했다.
- 픽셀 강제 표시를 제거해 확대 시 색상 경계가 자연스럽게 보이도록 했다.

## 검증

- `30 mm` 범위에서 `-15, -10, -5, 0, 5, 10, 15` 눈금 생성 확인
- X/Y 양 축에 0 눈금 포함 확인
- 물리 종횡비 유지 확인
- 색상표 시작·중간·최대값 확인
