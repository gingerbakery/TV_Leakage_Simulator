# Preview 목록·선택 작업·실행 상태 UI

코드 변경은 미커밋 상태다. 기능을 삭제하거나 광학 계산·GPU 커널을 바꾸지 않는다. 앞서 진행한 BSDF 혼합 경로 수정은 별도 변경이다.

## 작업 화면

- Preview 상단에 sticky 상태 카드와 선택 Leak 공통 작업 영역을 둔다. 뷰어 점 또는 후보 행의 선택 상태를 사용해 시야각 Receiver 생성·경로 검증·광량 비교·정밀해석 준비·ROI/Receiver 생성을 실행한다. 각 후보에 반복되던 작업 버튼은 제거했다. 대상이 없거나 조건이 맞지 않으면 비활성화한다.
- 후보 행은 선택 버튼·밝기·묶음 수 요약과 기본 닫힘 상세 정보로 구성한다. 후보 전체 접기, 100개 단위 페이지, 최대 높이 내부 스크롤을 유지한다. 뷰어 선택은 해당 페이지와 목록을 열어 보여 준다.
- Preview 광원/검출 방향/관찰 설정, 등록 광원, 각도 결과, Ray Tracing 광원/수광부, ROI, 재질 적용, 변환 목록에 공통 펼침·접힘을 적용한다. 기존 Block 그룹과 상세 형상 펼침·접힘은 유지한다. 공통 목록은 항목을 unmount하지 않아 접었다 펴도 편집값을 잃지 않는다. 연산 장치 정보는 원래의 상세 접기를 사용하며 GPU fallback 경고는 숨기지 않는다.
- 상태 카드는 실행 여부·진행률·서버 단계·완료/실패·작업 ID를 표시한다. 경로 검증의 pending 동안 회전 아이콘을 표시하고 성공/오류 후 제거한다. 이 아이콘은 요청 대기를 나타내며 서버 세부 진행률이나 정상 동작 보장은 아니다. 모션 감소 환경은 회전을 끈다.

## 경로 묶음

표시 위치의 거리와 내부 광원→관찰 면 polyline 패턴을 함께 비교한다. 관찰자 끝점은 시야각에 따라 바뀌므로 패턴에서 제외한다. 가까운 중복 점·일직선 위 추가 점을 정리하고 7개 호 길이 표본으로 경로 모양을 비교한다. 역전 경로, 떨어진 관찰 면, 다른 굴곡 경로는 합치지 않는다. 후보 중심은 지정 거리 이내, 실제 끝점도 거리 이내이며 시작점/경로 표본은 2배 거리 이내여야 한다.

수동 `유사 경로 묶기`에서 거리 1..100 mm(기본 15)를 조절할 수 있다. 포인트는 제거하지 않고 그룹 ID를 다시 연결한다. 기존 각도별 증거·원본 후보 ID·기존 묶음 수를 보존하며, 대표 경로/각도를 검사하는 것과 그룹 전체를 검증하는 것은 구분한다. 묶음이 물리적으로 같은 aperture나 같은 광량이라는 증거는 아니다. 원본 RayTraceResult는 유지한다.

마지막 수동 묶음 이전의 표시 목록/점/선택을 되돌릴 수 있다. 후보 삭제 시 삭제된 항목을 되살리지 않도록 되돌리기 이력을 해제한다. Case 또는 결과 run이 바뀌면 이력도 해제한다. 묶음 결과는 기존 Preview 결과 저장 경로를 사용하며 일시적 undo 기록은 프로젝트에 저장하지 않는다.

## 검증 및 한계

선택한 점의 대표 경로가 공통 경로 검증 요청에 전달되는지, 버튼이 후보마다 복제되지 않는지, pending 회전/완료 제거, 묶음 후 포인트 수 보존과 ID 연결/undo, 접힘 중 편집값 보존, 경로 패턴 차이와 역전 분리, 기존 각도별 그룹 통계를 검사했다. 실제 화면 전체를 GPU/CPU에서 벤치마크한 것은 아니다.

관련 frontend 9개 파일 108개 검사 및 production build 통과. 기존 큰 번들 경고는 유지된다. 상단 고정 영역이 Accordion의 가상 스크롤 컨테이너에 갇히지 않도록 Preview 콘텐츠만 `overflow: clip`을 사용한다.

넓힌 feature-editors 검사에서는 Enter 적용 2건이 실패했다. 현재 UI를 수정하기 전 HEAD `4cfb2e3`의 frontend를 별도 임시 폴더에 git archive로 추출해 같은 테스트를 실행했으며 동일 실패가 재현됐다(변환 편집 Enter 적용, Datum Emitter Enter 확정). 판정 조건을 완화하지 않았고 해당 편집기 동작은 이번 변경에서 수정하지 않았다. 후속 검증 항목으로 남긴다.

정상 화면의 새 사용 설명은 `(?)`에 두며 진행 상태·선택 대상·값·오류만 항상 표시한다. 사용자 서버 재시작·설치·커밋·푸시는 수행하지 않았다.
