# Preview 차폐 검사·직광 분류 보완

미커밋 변경. 사용자 우선순위에 따라 최외곽 개구부 자동 귀속은 보류하고 현재 검출·표시의 차폐와 직광 분류를 보완했다. 실제 사용자 TV 도면의 원인이 확정됐다는 보고가 아니다.

## 수정한 경로

- 관찰 휘도 표본의 합산 휘도는 그대로 두고, 직광 기여가 실제로 있으면 직광 경로를 먼저 보존한다. 기존에는 반사 기여 하나가 더 크면 직광이 있는 표본도 반사로만 분류될 수 있었다. 표본→셀→chunk 병합→후보 병합에서 직광 경로가 밝은 반사 경로에 덮이지 않도록 CPU/주재 CUDA 커널·compact reducer·경로 탐색 reducer·프런트엔드 대표 선택을 맞췄다.
- `direct_presence_priority_v1`로 새 분류를 식별한다. 직광 포함 표본과 반사만 있는 표본 수는 배타적이며 합이 양수 기여 표본 수다. 이는 직광 우세/육안 가시성 판정이 아니다.
- 셀별 `direct_luminance_nit`와 `reflected_luminance_nit`를 분리해 평균 추정 휘도를 기록한다. 후보의 각 성분 최대값과 대표 경로의 직광/반사 횟수를 표시한다. 성분 최대는 각각 다른 셀일 수 있어 두 최대를 더해 최고 총 휘도로 해석하면 안 된다. 설명은 `(?)`에 둔다. 이전 결과는 새 분류가 아니라는 상태를 표시한다.
- 관찰자 샘플점으로 가는 마지막 선분에 CAD 종점용 허용오차를 적용해 관찰 점 직전의 얇은 구간을 누락하던 검사를 고쳤다. 실제 CAD 반사 종점의 표면 허용오차는 유지한다.
- Stop 부분 결과와 일시 중단 스냅샷에도 대표 경로 독립 기하 감사를 적용한다. 기존에는 최종 완료 결과만 감사했다. 차폐 실패 경로는 기존 후보 제외 규칙을 따른다. 중단 스냅샷은 복사본이며 live RNG/누적기/재개 세션을 변경하지 않는다.
- 역추적 Preview 요청은 빠른 샘플 설정에서도 정밀 CAD 형상을 요청한다. 단순화된 뷰어 mesh의 누락을 실제 홀로 해석하지 않기 위함이다. 최초 정밀 tessellation/BVH 준비 시간이 늘 수 있지만 기존 캐시를 재사용한다. 샘플 수·각도 예산을 자동 증가시키지는 않는다.

## 확인

합성 장면에서 직광 1 nit + 거울 반사 90 nit가 함께 있어도 총 91 nit를 유지하고 직광 경로와 성분 1/90을 보존한다. 같은 장면의 CUDA 커널 수식을 CPU oracle로 실행해 합계·직광·반사 경로 선택을 확인했다. 이는 실제 GPU 컴파일/실행 증거가 아니다. 실제 CUDA 검증 스크립트에도 이 혼합 장면과 직광 성분 일치 gate를 추가했다.

카메라 바로 앞 `0.5·epsilon` 위치에 놓인 차폐판을 통과 경로로 허용하지 않는 회귀 테스트를 추가했다. Stop/재개 검사에서 부분 결과 기하 감사가 있는지와 최종 누적·경로 보존을 확인했다. Compact/ordered reducer의 새 광량 필드에도 기존 총 휘도와 동일한 `max(1e-12, |reference|·1e-12)` FP64 허용오차를 적용하고 모든 이산 결과·경로의 정확 일치는 유지했다.

같은 합성 장면에 이전 두 종점 검사 조건을 메모리에서 복원해 대조했다(파일 변경 없음). 이전 검사는 `valid / virtual_emitter`, 현재 검사는 `invalid / occluded_segment`를 반환했다. 실제 사용자 도면의 원인과 동일하다는 뜻은 아니다.

관련 backend 123개, frontend 6개 파일 101개 통과. 프런트엔드 production build 통과(기존 큰 번들 경고). 실제 TV `.bitsam` 재현과 NVIDIA GPU 실행 검증은 미실시다. 작업 환경의 GPU 부재는 이전 읽기 전용 점검 결과이며 설치·서버 재시작·커밋·푸시는 수행하지 않았다.

## 해석 한계

내부 면이라도 실제 gap을 통해 관찰자에게 보이는 면은 유효 관찰점이다. 내부라는 이유로 제거하지 않는다. 물리적으로 차폐된 경로를 제거하는 것과 실제 외장 출구에 점을 귀속하는 것은 별개이며 후자는 아직 미구현이다.

직광의 기준은 현재 설정한 발광면이다. 확산판 후방 등가 광원·Aim·방출 방향이 실물 LED와 다르면 실물에서 직광처럼 보이는 점이 계산에서는 반사 경로가 될 수 있다. 이번 변경으로 실제로 표본화되지 않은 직광을 만들어내거나 광원/재질을 임의 변경하지 않는다. 좁은 gap·관찰 각도·미관측 경로의 미검출과 실제 CAD 누락 여부는 사용자 도면 조건으로 후속 확인이 필요하다.
