# 3D 빛샘 보기 외관 가시성 개선

## 문제와 수정

합성 샘플의 거의 검정인 CAD 색을 그대로 사용하고 보조 조명까지 낮춰, 검정 배경에서 형상을 식별할 수 없었다. 기존의 보조 조명만으로 충분하다고 본 시각 검증은 부족했다.

- 기본 외관은 블랙 표시 프리셋과 밝기 60%를 사용한다. 블랙/그레이/실버, 무광/반광, 외관 밝기 0–100%를 3D 결과 화면에서 조절할 수 있다.
- 카메라에 연결한 외관 전용 방향광으로 회전한 면도 식별되도록 했다. 일반 Viewer로 돌아가면 기존 CAD 색과 조명을 복원한다.
- 외관 조명은 실제 주변 lux가 아닌 형상 확인용이다. UI에 표시 목적을 안내하며 완료 결과의 광학 물성, 광선 에너지, 상대 표시 계수, 노출, 가림 깊이는 바꾸지 않는다.
- 밝기 조절은 조명 세기만 바꾸며 빛샘 geometry나 카메라 Fit을 다시 만들지 않는다. 색/마감은 표시 재질만 갱신한다. 기존 선택의 주황색 강조도 3D 빛샘 보기에서는 적용하지 않는다.
- 표시 설정은 현재 Viewer 세션의 상태이며 BITSAM 저장 항목은 아니다.

## 검증

- 외관 조절 후 원본 Result, source request, 출구 표본, 카메라 요청이 유지되고 일반 Viewer에서 컨트롤이 숨겨지는 통합 테스트를 추가했다.
- 관련 4개 테스트 파일 32개 테스트, TypeScript 검사, lint, production build 통과.
- 실제 로컬 시연 gap_0p5를 CPU로 실행: rt3-829b7f8122a8, 20,000 rays, 113 receiver hits, 0.565%. 외관 밝기 0%/60%에서 같은 위치의 빛샘을 유지하고 외관만 변하는 것을 확인했다.
- 블랙/그레이, 무광/반광 조절, 사선 회전 시 코너 틈과 외관 표시, Result 복귀를 확인했다.

## 남은 범위

연속광의 표본 흔적과 AABB 출구 근사, 실제 gap surface 추출, 절대 nit와 육안 검출 한계 보정은 기존 한계로 남는다.
