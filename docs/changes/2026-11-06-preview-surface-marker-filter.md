# Preview surface marker display filter

The viewer now displays only points that match a geometry-audited, observer-visible CAD endpoint in the stored observer summary, at the same observer angles. Intermediate bounces, envelope intersections, averaged coordinates, virtual-emitter endpoints and unaudited legacy coordinates are excluded from marker rendering. Detection evidence, saved results, candidates and analysis actions remain unchanged. Legacy/forward-only results can consequently have candidates but no rendered points; a current audited observer run is required for markers.

Both marker core and halo now depth-test against rendered geometry. This removes the previous through-wall overlay; hidden CAD does not contribute depth. This is not an exterior-aperture classifier: an internal surface genuinely visible through a gap remains eligible, and an illuminated exterior surface can remain eligible. Group representative arrows still describe the group, not necessarily an individual point; per-point path selection remains unresolved.

Validation: leak-preview-model.test.ts, 33 tests passed, including exclusion of an intermediate first bounce, floating estimate, missing/invalid/unverified audit, wrong observer angle and virtual source. Production frontend build passed. No live scene or physical opening attribution validation was performed, and no GPU execution was performed.

Identical position/observer-angle/candidate markers are also deduplicated, retaining the strongest display sample without summing brightness. Distinct angles/candidates are retained so angular highlights and candidate selection remain usable. This does not merge internal and exterior positions into one aperture: path-to-aperture provenance is still missing. Transparent CAD surfaces currently disable depth writes, so depth testing alone does not guarantee occlusion in transparent/hidden/sectioned display modes. The physical CAD path audit remains independent of these display settings.
