# CAD 연결 실패 후 다시 연결

완료 결과를 비교할 때 CAD가 바뀌면 현재 정책상 장면 데이터를 다시 불러온다. 사용하지 않는 장면 쿼리는 즉시 제거해 서버 메모리에만 존재하는 scene_token을 오래 재사용하지 않는다. 따라서 로컬 API 서버가 종료되면 Case를 바꾸는 시점에 장면 불러오기가 실패할 수 있다.

현재 쿼리는 네트워크/서버 오류를 한 번 재시도한 뒤 오류 화면에 머문다. 로컬 서버가 다시 실행되어도 브라우저의 네트워크 연결 상태가 바뀌는 것은 아니므로 자동 복구가 보장되지 않는다.

기존 Scene load failed 패널에 ‘다시 연결’ 버튼을 추가했다. 버튼은 현재 장면 쿼리의 refetch만 실행한다. Case 선택, 완료 결과, 광학 조건이나 광선 추적을 초기화하지 않는다. 비교를 시작하며 캡처한 카메라 위치도 오류와 로딩 화면 동안 유지되어 장면이 복구된 뒤 적용된다. 폴링·캐시·오류 분류 정책은 변경하지 않았다.

회귀 검증은 비교 Case에서 연결 실패 → 다시 연결 → 로딩 → 장면 복구 순서를 확인하고, Case/완료 결과 객체와 카메라 스냅샷이 유지됨을 검사했다. 실제 QueryObserver의 실패 상태를 명시적 refetch로 성공 상태로 복구하는 검사도 추가했다. 관련 화면/쿼리 테스트 11개와 TypeScript, 대상 lint, 변경 형식 검사 및 production build가 통과했다.

새 버튼은 새 프런트엔드 빌드가 로드된 뒤 적용된다. 열려 있는 기존 시연 탭은 결과를 보존하기 위해 새로고침하지 않는다. 기존 화면에서는 서버 복구 후 다른 완료 Case를 선택했다가 원하는 Case로 돌아와 장면을 다시 요청할 수 있다.
