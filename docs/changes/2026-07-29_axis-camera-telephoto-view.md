# 축 카메라 프리셋 원근 왜곡 축소

## 문제

- `XY`, `YZ`, `ZX` 카메라 프리셋이 일반 `42°` Perspective Camera를 사용했다.
- 축 방향을 정확히 맞춰도 카메라와 가까운 형상은 크게, 먼 형상은 작게 보여 옆면과 깊이 방향 원근감이 나타났다.
- CAD 정면도처럼 한 축에 수직인 평면 투영으로 보기 어려웠다.

## 변경

- `XY`, `-XY`, `YZ`, `-YZ`, `ZX`, `-ZX` 프리셋의 시야각을 `0.75°`로 변경했다.
- 카메라를 모델에서 충분히 멀리 배치하는 장초점 방식으로 정투영에 가까운 화면을 만든다.
- 기존 Perspective Camera와 Trackball 조작 구조를 유지하므로 회전, 줌, ROI 선택, Current View Receiver 기능은 그대로 사용할 수 있다.
- `Iso` 프리셋을 누르면 기존 `42°` 시야각으로 복귀한다.
- `Fit`은 현재 시야각을 유지하므로 축 뷰에서 Fit을 눌러도 원근감이 다시 생기지 않는다.
- ROI 박스 선택을 위해 축 뷰로 임시 전환할 때 기존 FOV를 함께 저장하고, 선택 종료 후 정확히 복원한다.

## 검증 기준

- 여섯 축 프리셋 모두 `0.75°` FOV를 사용한다.
- `Iso`는 `42°` FOV를 사용한다.
- 축 뷰 상태의 `Fit`은 `0.75°` FOV를 유지한다.
- Current View Receiver는 카메라의 target, normal, u/v 축만 사용하므로 생성 위치·방향 계약은 변하지 않는다.
