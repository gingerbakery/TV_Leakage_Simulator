# 경로 탐색 양성·관찰 휘도 미검출의 재현 수정

사용자는 같은 광원·재질·Block·시야각에서 관찰 휘도 기본 0.01 nit·2 mm가 미검출이라고 보고했다. 사용자 도면 자체를 받아 재현한 것은 아니며 아래 코드는 별도 합성 장면으로 검증했다.

## 재현한 결함

가상 Datum과 실제 CAD 면이 겹칠 때 경로 탐색은 광원 교점이 첫 CAD hit와 동일한 경우를 수치 허용오차 내에서 인정했지만, 관찰 휘도 CPU 및 resident CUDA 수식은 `source_t < cad_t`만 허용했다. 따라서 같은 발광면을 경로 탐색은 검출하고 휘도는 0으로 누락했다. 검은 CAD 평면 위 Lambertian/후방 Sphere Uniform Datum에서 수정 전 실패를 먼저 확인했다.

동일한 교차 event의 가상 발광을 허용하도록 `1e-9 mm`의 수치 일치 기준을 맞췄다. CAD/광원을 epsilon만큼 이동하거나 차폐판을 무시하지 않는다. Lambertian은 100 nit, 후방 Uniform은 동일 flux 계약에서 50 nit라는 합성 해석해를 CPU 추적과 CUDA 커널 CPU 수식 oracle로 확인했다.

등록된 Block 표면이 Datum과 겹친 경우에는 Block을 새 광원처럼 취급하지 않는다. 광원 연결(NEE) shadow ray도 끝점까지 검사하고, 발광 CAD 끝점은 인정하되 그 이전 기구물과 끝점의 Block은 차폐로 처리한다. 이 규칙은 경로 탐색/관찰 휘도/resident 수식에 같이 적용했다. 광원 쪽에서만 생긴 차폐 누락을 검증할 수 있도록 대표 경로 감사에도 광원 연결 역방향 끝점 검사를 추가했다. 기존 저장 경로가 해당 조건에 걸리면 `source_covered_by_blocker`로 제외한다.

실제 CAD를 가상의 광원으로 대체하는 모델에서 광원과 Block의 위치가 겹친 경우는 설정 확인이 필요하다. 이번 수정은 모든 사용자 형상의 물리 모델 정확도를 보장하거나 실제 틈을 자동으로 식별하는 기능이 아니다.

## 미검출 진단

완료된 셀에서 Allowed 영역을 제외한 뒤, 최소 휘도 적용 전 최고 셀 평균 휘도와 양수 기여 표본 수를 기록한다. threshold로 제외된 표본 수도 표시한다. 미검출 상태는 최소 휘도 미달, 이번 관찰 표본에서 휘도 기여 미검출, Allowed 제외, 대표 경로 차폐/조건 불일치로 구분한다. 부분 결과는 완료된 셀 기준이고 미완료 셀을 포함하지 않는다. 기존 결과에 없는 값은 임의로 생성하지 않는다.

경로 탐색은 셀 중앙·지터와 광원 투영 표본을 사용하지만 관찰 휘도는 면적 적분의 확률 가중 표본을 사용한다. 따라서 좁은 틈/작은 각도의 실제 경로는 여전히 놓칠 수 있고, 존재하는 경로가 0.01 nit 이상의 셀 평균 휘도를 보장하지 않는다. 발견 경로를 가중치 없이 nit에 합산하지 않는다. 광원 출력·재질·각도·2 mm 간격·0.01 nit를 자동 변경하지 않았다.

## 확인 범위

동일 면 발광, 앞의 차폐판(1 mm 및 0.00001 mm 간격), Datum과 같은 면의 Block, 반사점→광원 연결 끝점의 Block, 정상 threshold 제외/필터 전 최고, 새 미검출 화면 문구를 확인했다. 관련 backend 130개, frontend model/panel 60개 검사와 production build가 통과했다. 기존 번들 경고는 유지된다.

실제 NVIDIA GPU 실행은 검증하지 못했다. resident 실제 장치 optical preflight 및 검증 스크립트에 coplanar/차폐 장면 gate를 추가했으며 GPU 성공은 사용자 PC의 실제 CUDA 증거가 필요하다. 이전 실행 결과에는 이 수정이 적용되지 않으므로 수정 버전에서 동일 조건으로 새 실행이 필요하다. 커밋·푸시·설치·사용자 서버 재시작은 수행하지 않았다.
