# 과검출·미검출 분석 검증 — 2026-11-05

## 결론

현재 `observer_path_support_v1`은 경로 존재 검출이며, 사용자가 요구한
“TV를 켜고 관찰 위치를 돌리며 실제로 밝게 보이는 빛샘 검출”의 합격 기준을
충족하지 못한다. 합성 장면 16개에서 TP 6, TN 3, FP 4, FN 3을 재현했다.
이 숫자는 의도적으로 구성한 반례의 수이며, 실제 TV의 정확도·과검출률·미검출률
추정치가 아니다. 생산 검출기의 가시성 합격 결과는 **FAIL**이다.

재현 프로그램과 테스트가 정상 동작했다는 것과, 제품의 가시성 검출이 합격했다는
것을 구분한다. 스크립트는 현재 결과에서 종료 코드 **2**를 반환한다.
임계값이나 합격 기준을 바꾸어 실패를 통과시키지 않았다.

## 시험 기준과 독립 증거

- CPU BVH의 현재 제품 역추적 함수를 실제 실행했다. GPU 실행·성능 검증은 하지 않았다.
- `검출 경로 수 > 0`을 사용자 목표의 가시 빛샘 검출로 해석할 경우를 평가했다.
  경로 존재라는 원래 계약에서는 매우 약한 경로도 진짜 경로일 수 있으므로,
  FP는 모두 기하 교차 오류라는 뜻이 아니다.
- 비교 기준은 분해 가능한 이상적 영상 위치의 선형 휘도 **1 nit**로 설정한
  합성 판정이다. 실제 육안 가시성 표준이나 UI 기본값을 제안한 것이 아니다.
  실제로는 각크기·배경·노출·대비·순응 조건 등이 추가로 필요하다.
- 직광의 Lambertian 광원 휘도 L, 이상 정반사의 R×L, 비음수 BRDF 적분의
  상·하한을 제품의 경로 수와 독립적으로 계산했다.
- 작은 gap과 두 번 반사 경로는 좌표와 직선·반사 법칙으로 존재를 증명했다.
  CPU/GPU 일치나 많은 Ray 수를 물리적 정답의 근거로 삼지 않았다.
- 원시 JSON은 각 장면의 정점·삼각형·재질·광원·관찰 조건·완료 상태·검출 수와
  SHA-256 입력 해시, 검증 대상 커밋 및 소스·스크립트 해시를 보관한다.

## 과검출 반례

| 장면 | 독립적인 밝기 기준 | 현재 검출 | 판단 |
|---|---|---:|---|
| 직접 보이는 매우 어두운 광원 | 0.000001 nit < 1 nit | 직광 16 | 가시성 FP |
| 같은 장면의 밝은 광원 | 100 nit > 1 nit | 직광 16 | TP 대조군 |
| 매우 약한 이상 정반사 R=0.000001 | 0.0001 nit < 1 nit | 반사광 16 | 가시성 FP |
| 같은 장면의 R=0.9 | 90 nit > 1 nit | 반사광 16 | TP 대조군 |
| 합성 BSDF의 미약한 RT | 상한 0.0001 nit < 1 nit | 반사광 1,600 | 가시성 FP |
| 합성 BSDF의 충분한 RT | 중심 휘도 하한 약 68.77 nit | 반사광 1,600 | TP 대조군 |
| 80° 방향의 미약한 BSDF 꼬리 | 상한 약 0.00000000104 nit | 반사광 148 | 가시성 FP |

합성 BSDF는 알려진 수치로 구성한 컴파일된 표를 소비하는 경로를 검사했다.
특정 업체의 측정 BSDF나 파일 파서, 실제 TV 재질의 정확도를 검증한 것은 아니다.

원인은 광원 세기·반사량·BSDF 값과 표본 확률을 밝기로 누적하지 않고,
값이 양수인지로 지지되는 경로를 세는 것이다. 경로 수만으로 가시성이나 각도별
밝기 순위를 정할 수 없다는 반례이다.

## 미검출 반례

| 장면 | 실제 존재하는 경로 | 거친 조건 | 비교 조건 | 판단 |
|---|---|---:|---:|---|
| 폭 0.1 mm의 두 gap | H=52.5°, V=7.5° 중심선 | 15° 반구 145방향: 0 | 해당 방향 검사: 40 | 각도 간격에 의한 FN |
| 중심이 어긋난 폭 0.08 mm gap | H=0°, V=0°의 직선 | 검사 간격 2 mm: 0 | 0.1 mm: 15 | 공간 표본에 의한 FN |
| 이상 거울 두 개 | 광원→거울→거울→관찰자 | 최대 반사 1회: 0 | 2회: 19 | 깊이 제한에 의한 FN |

각도·공간 시험은 다른 반사 횟수와 혼동하지 않도록 최대 깊이를 3으로 두고
나머지 벽은 반사율 0으로 구성했다. 두 gap에서의 변위 차이를 이용하면
15° 격자의 모든 비평행 방향이 해당 통로를 통과하지 못함을 계산할 수 있다.
정답 방향에서는 유한 크기의 실제 열린 영역과 광원이 존재한다.

공간 시험은 gap 중심 (0.137, 0.173) mm, 폭 0.08 mm이며,
0.1 mm 격자의 (0.15, 0.15) mm 광선이 두 gap과 광원 안에 든다.
이 반례는 해당 고정 표본열에서의 결과이다. 모든 작은 gap에서 같은 미검출률을
보장한다는 뜻은 아니며, 제품 역추적 RNG가 고정된 표본열을 사용하기 때문에
같은 조건을 단순 재실행하는 것은 독립적인 신뢰도 검증이 아니다.

## 차폐 대조군

정면 단일 관찰 방향에서 다음 세 조건은 모두 직광 0, 반사광 0이었다.

- gap 없는 닫힌 불투명 벽
- gap을 가리는 추가 면: ACC가 이미 교차 검사 mesh에 합성됐다고 가정한 대조군
- gap을 막는 반사율 0.9의 원형 마개

ACC 파일의 불러오기·합성·Case 선택 파이프라인 전체를 이 대조군으로 검증한
것은 아니다. 실제 사용 도면의 특정 홀이 막혔는지, ACC의 단위·위치·상태가
맞는지는 해당 저장 파일을 별도로 검사해야 한다.

## 수정 우선순위

1. 관찰 카메라의 위치·방향·화각에 대응하는 선형 휘도/방사휘도 영상을 계산한다.
   광원·BRDF·RT·표본 PDF·다중 반사 에너지를 반영하고 경로 수와 분리한다.
2. 거친 전역 검색 후 각도와 공간을 적응적으로 세분한다. 광원 추적 Ray 수만
   올리는 것은 역추적 각도 간격과 공간 표본의 누락을 해결하지 않는다.
3. 반사 깊이·표본 부족·중지 결과를 미검출/빛샘 없음 판정과 구분하고 불확실성을
   표시한다. 약한 경로를 임의로 삭제하거나 Priority를 높여 정확도를 꾸미지 않는다.
4. 실제 TV의 `.bitsam`과 같은 관찰 각도의 실측/렌더 영상·광원·재질 조건을
   대조해 밝기/대비 기준과 오검출·미검출 위치를 검증한다.
