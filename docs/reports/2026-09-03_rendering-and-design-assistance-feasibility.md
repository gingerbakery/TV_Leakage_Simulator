## 1. 사용자의 의도

### 외관 빛샘 렌더링

리시버 수치와 광선 경로를 해석해야 하는 현재 사용 경험을 확장한다. 사용자가 세트의 관측 위치를 정하면, 빛이 실제로 나오는 틈과 주변 표면에서 어떻게 보이는지를 영상으로 확인한다. 주변 조도와 관측 조건에 따른 차이, 설계 변경 전후의 상대 밝기를 함께 비교한다.

예를 들어 동일한 하단 틈을 정면과 사선에서 보거나, 암실과 조명이 있는 환경에서 볼 때 밝은 선의 위치·폭·강도가 어떻게 달라지는지 확인하는 기능이다. 광선 경로와 정량 리시버는 영상의 원인을 설명하고 검증하는 데 계속 활용한다.

### 빛샘 개선 설계 지원

사용자가 문제 영역을 지정하면 프로그램이 원인을 좁히고, 변경 가능한 구조·치수·재질의 후보를 만들어 실제 재해석으로 비교한다. 초기에는 제한된 설계 변수와 몇 종류의 차광 구조부터 시작하며, 추천 이유·변경 형상·계산된 개선 정도를 함께 제시한다.

장기적인 연결은 `외관에서 문제 선택 → 누설 원인 확인 → 개선안 생성 → 재해석 → 전후 외관과 수치 비교`이다.

## 3. 렌더링의 핵심 설계

### 계산해야 할 대상

리시버에 들어오는 광량과 특정 관측 방향으로 보이는 휘도는 서로 다른 물리량이다. 따라서 리시버 히트맵을 제품에 붙이는 기능은 진단용으로 활용할 수 있지만, 외관 영상에는 위치와 방향에 따른 빛의 계산이 추가되어야 한다. 조도는 lux, 관측 휘도는 cd/m²로 관리한다. [근거: PBRT의 측광량 정의](https://pbr-book.org/4ed/Radiometry,_Spectra,_and_Color/Radiometry)

처음에는 단색 휘도 영상으로 범위를 좁히는 것이 적합하다. 직접 보이는 광원·틈과 표면 반사광을 포함하고, 가림을 관측 시점에서 판정한다. 공중의 광선 자체를 빛나는 선으로 그리는 기능은 원인 설명용 표시로 취급한다.

기술적으로는 공통 CAD·광원·광학 재질을 입력받는 관측 렌더링 모듈을 추가한다. 현재 전방 광선 추적 함수를 그대로 역방향 호출하는 방식은 보장되지 않는다. 방향별 반사 평가, 샘플 확률, 광량 가중치의 일관성을 정의해야 하며, 좁은 틈과 다중 반사 경로를 충분히 찾는 표본 전략도 검증한다. [근거: PBRT의 광전달 방정식과 경로 적분](https://www.pbr-book.org/4ed/Light_Transport_I_Surface_Reflection/The_Light_Transport_Equation)

초기 검증 범위는 Lambertian 광원·확산면 중심으로 고정한다. 경면 경로는 별도 검증 장면을 통과시켜 추가한다. 현재 Gaussian/Mixed 모델은 정규화된 방향 PDF 계약에 제약이 있으므로 관측 렌더러의 지원 여부와 근사 방식을 명시해야 한다. 관련 저장소 문서는 `docs/perf4e-receiver-importance-sampling.md`이다.

### 주변 조도와 화면 표시

- 환경 입력은 `lux + 조명 분포 가정 + 측정 기준 위치·면 방향`으로 정의한다. 같은 lux라도 조명 방향과 주변 반사에 따라 세트 외관이 달라진다.
- 초기에는 균일 확산 환경 같은 제한된 모델과 사용자 지정 lux로 시작한다. 이후 실제 조명 배치·환경 영상·벽 반사로 확장한다.
- TV 화면의 점등 상태와 검정 화면 휘도도 관찰 조건에 포함한다. 주변 대비에 영향을 주기 때문이다.
- 선형 휘도 원본을 저장하고, 노출·톤 매핑·색상지도는 표시 단계에 적용한다. 화면 픽셀값을 다시 설계 평가값으로 사용하지 않는다.
- 설계 A/B는 같은 관측 위치·화각·해상도·환경·노출·스케일로 비교한다. 자동 노출은 실제 광량 차이를 가릴 수 있다.
- 육안 체감 모드는 적응 상태와 표시 장치의 한계를 포함하는 후속 기능으로 둔다. 암실에서의 사람 시각을 단순 밝기 슬라이더로 완전히 재현한다고 설명하지 않는다. [근거: Radiance pcond의 시각 반응·디스플레이 변환](https://www.radiance-online.org/archived/radsite/radiance/man_html/pcond.1.html)

### 세트 전체와 ROI

외관 렌더링에서는 관측 영역 밖의 부품도 빛을 막거나 반사할 수 있다. 렌더링용 장면에는 필요한 주변 형상을 보존해야 한다. 화면에 전체 CAD를 보여주는 것만으로 ROI 해석에서 제거된 부품의 광학 효과가 복구되지는 않는다.

국부 계산을 유지하려면 ROI 경계로 들어오고 나가는 빛의 조건을 정의하고, 필요한 주변 형상을 늘렸을 때 결과가 안정되는지 확인한다. 최종 렌더링과 최종 설계 검증에는 같은 장면 범위를 사용한다.

### 필요한 데이터와 검증

새 데이터 계약은 관측 카메라, 환경 조건, 선형 휘도 영상, 표본 품질, 지원 광학 모델, 보정 이력을 포함한다. 결과는 사용한 형상·광원·재질·카메라 버전과 연결해 재현할 수 있게 한다.

실제와의 정합에는 대표 샘플의 광원 출력·배광, 재질 반사 특성, 고정 촬영 조건의 사진, 가능하면 휘도계 측정이 필요하다. 사진의 자동 노출이나 휴대폰 HDR 결과만으로 절대 휘도를 보정하지 않는다. 한 조건으로 보정한 뒤 다른 각도·조도와 별도 샘플에서 확인한다.

현재 필름·확산판도 반사 중심의 근사이며 투과·굴절·측정 BSDF 처리는 별도 범위다. 대표 빛샘의 지배 원인이 필름 투과나 체적 산란이면 해당 물리 모델이 선행되어야 한다. 초기 상대 비교의 유효성도 지원되는 광학 현상 안에서 검증한다.

## 4. 자동 개선 설계의 단계

### B1 — 기존 설계 변수의 자동 비교

문제 영역, 수정 가능한 부품, 변수 범위, 고정 조건을 지정한다. 프로그램이 부품 이동·간격·각도·허용된 재질 프리셋의 후보를 만들고 순차 재해석한다. 광원 출력을 낮추거나 정상 발광 영역을 가리는 후보가 개선안으로 선택되지 않도록 고정 조건과 제약을 둔다.

초기 알고리즘은 소수 변수의 범위 탐색과 유망 구간 재탐색으로 충분하다. 별도 학습 데이터가 없어도 시작할 수 있다. 사용자는 후보별 변경량, 개선 수치, 계산 품질, 원인 설명을 보고 결과를 선택한다. 렌더링 완성을 기다리지 않고 기존 리시버 지표로 착수할 수 있다.

현재 부품별 수신 기여도는 모든 상류 부품의 인과적 영향과 동일하지 않다. 일부 집계는 수신 직전 반사면에 귀속되며, 선택 영역의 경로 분석도 저장된 경로 표본에 의존한다. 이를 후보 위치를 정하는 단서로 사용하고, 예상 감소율은 후보의 실제 재해석으로 계산한다.

### B2 — 차광 구조 템플릿 생성

차광판, 립, 겹침 구조, 테이프·폼 영역 등 몇 가지 형상 유형을 정의한다. 위치·길이·높이·두께·각도·재질을 변수로 삼아 해석 가능한 형상을 만들고 동일한 탐색 절차를 적용한다. 예를 들어 문제 틈 안쪽에 립을 추가한 후보를 만들고, 외관 영상과 수치를 원래 구조와 나란히 비교한다.

추가 형상은 mesh 생성, 부품 ID, 재질 할당, 저장·복원, 해석 장면 반영까지 연결해야 한다. 테이프나 폼도 초기에는 형상과 광학 특성만 모델링하며 접착·압축 변형까지 계산한다고 가정하지 않는다. 원래 STEP의 설계 이력과 편집 가능한 solid로 반영하는 기능은 후속 CAD 연동 과제다.

### B3 — 다중 조건과 제조 제약을 포함한 탐색

여러 관측 방향, 조도, 공차 조건에서 개선이 유지되는지 평가한다. 최소 두께·조립 간격·체결부 회피·허용 공간 등의 제약을 함께 검사한다. 금형·조립·열·강도 조건은 입력과 검사 기능이 있는 항목만 검증 완료로 표시한다.

추천은 광학 개선 정도와 구조 변경 부담을 함께 보여준다. 데이터가 쌓이면 탐색을 빠르게 하는 예측 모델과 사내 설계 사례를 추가할 수 있다. 자유형상 최적화는 장기 후보이며, 형상 변화와 광학 모델을 함께 다뤄야 하는 별도 연구 범위다. [관련 사례: Mitsuba의 형상 최적화](https://mitsuba.readthedocs.io/en/latest/src/inverse_rendering/shape_optimization.html)

### 목표와 신뢰도

- 초기는 총 누설 광량, 일정 면적에서의 밝기, 밝은 영역 크기를 함께 비교한다. 전역 p95만으로 작은 강한 빛샘이 사라지거나, 단일 noisy peak만으로 순위가 결정되지 않도록 한다.
- 렌더링 연결 후에는 관측 영상의 선택 영역 휘도와 주변 대비를 추가한다. 색상지도나 톤 매핑 결과 대신 원본 계산값을 사용한다.
- 한 위치를 개선하면서 다른 틈이나 관측 방향이 악화되는지 확인한다. 가능한 후보가 없으면 제약 내 개선안을 찾지 못했다고 보고한다.
- 탐색에는 동일 조건과 정해진 seed 묶음을 사용하고, 최종 후보는 독립 seed와 충분한 표본으로 다시 검증한다. 저장 경로 수나 화면의 선 개수로 평가하지 않는다.
- hit가 0이라는 이유만으로 완전 차광이라고 판정하지 않는다. 표본 수, 통계 품질, 후보 간 차이의 안정성을 함께 확인한다.
- 현재 통계오차는 광선 표본의 오차 추정이다. 형상·광원·재질 모델의 오차까지 포함하는 정확도 보증으로 사용하지 않는다.
- 후보 수·계산 시간 예산·중단·결과 보존을 관리하는 Study 기능을 추가한다. 현재 단일 해석 시작 API를 병렬 호출하면 기존 작업이 중지될 수 있다.
- 현재 추가 해석·수렴 제어는 frontend가 담당하므로, 자동 탐색에서는 창의 상태와 독립적으로 실행되는 Study 계층에 해당 정책을 연결한다.

## 5. 권장 개발 순서와 완료 기준

| 단계 | 사용자에게 제공되는 결과 | 다음 단계로 넘어가기 위한 확인 |
| --- | --- | --- |
| 공통 준비 | 대표 사례와 관측 조건, 수정 허용 영역, 비교 기준 확정 | 지배적인 빛샘 원인이 지원 모델로 표현되는지 확인 |
| A1 외관 기본형 | 한 관측 시점의 단색 빛샘 영상, 휘도 지도, 고정 노출 A/B | 직접 노출·확산 반사 장면 검증, 광원 변화에 대한 선형 원본 일관성 |
| B1 변수 탐색 | 기존 부품 위치·간격·재질 후보의 자동 해석과 순위 | 동일 조건 비교, 독립 seed 재검증, 원본과 후보 재현 가능 |
| A2 환경·실측 | 정의된 조명 모델의 lux 변경, 실물 보정, 관측 각도 확대 | 조명 조건과 노출 기록, 별도 조건·샘플에서 정합 확인 |
| B2 구조 추천 | 차광 구조 템플릿의 생성, 계산, 전후 외관 비교 | 실제 형상이 해석에 반영되고 설정된 간섭·공간 제약 통과 |
| A3/B3 고도화 | 재질·시각 모델 개선, 다중 조건과 공차를 고려한 설계 | 사내 대표 사례에서 개선 순위·정확도·재현성 확인 |

A1과 B1의 병행은 최초 검토안이었다. 후속 사용자 결정에 따라 현재는 암실 렌더링만 진행 범위로 잡고, B1을 포함한 자동 설계는 V1 완료 이후에 검토한다. 실행 시간을 측정하지 않았으므로 실시간 렌더링이나 전체 개발 기간은 아직 확정하지 않는다.

자동 설계가 추가될 후속 버전의 사용 흐름은 `빛샘 위치 선택 → 기준 외관/수치 확인 → 허용 범위 내 후보 계산 → 상위 후보의 형상·수치·외관 비교`를 참고한다. 현재 암실 시제품에서는 기준 외관과 모델별 밝기·크기 비교까지만 다룬다.

## 6. 다음 상세 검토에 필요한 입력

1. 첫 대상으로 삼을 대표 빛샘 위치와 가능하면 개선 전후 실물 사례.
2. 관측 거리·각도·주변 조도·TV 화면 상태. 확보 가능한 사진 또는 휘도 측정.
3. 수정 가능한 부품과 치수 범위, 추가 가능한 차광재·구조, 변경 금지 영역.
4. 우선 목표: 밝은 점의 억제, 밝은 선의 폭·길이 감소, 전체 누설량 감소 중 무엇이 중요한지.

이 정보는 후속 상세설계와 실측 검증에 사용한다. 현재 1차 검토의 결론은 두 기능 모두 단계적으로 적용 가능하며, 관측 렌더링과 후보 재해석을 공통 광학·형상 데이터 위에 연결하는 방향이 적합하다는 것이다.
